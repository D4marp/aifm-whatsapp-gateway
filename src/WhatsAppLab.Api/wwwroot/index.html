2. Settings (feature is Off by default)

a random 0..N s is added to every gap
Preset = what the team suggested: about 10-15 a day, in uneven waves (e.g. 3 messages, then a pause of 1.5 h), only in working hours. It lowers the chance of a block, it does not remove it. Hours use this PC's clock.

3. Send a message (trigger: API)

The message goes into the outbox; the background worker sends it when Enabled is on, the hours, wave and daily limits allow. Until then it stays Pending.

4. Recurring announcement (Hangfire)

Sends the text and group chosen in step 3, on a schedule. Cron is in UTC (e.g. 0 2 * * * = 09:00 in Batam). The job only puts the message in the outbox, so every limit above still applies.
